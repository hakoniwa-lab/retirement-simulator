# 退職金手取りシミュレーター MVP

退職金の額面と勤続年数を入力するだけで、退職所得控除を踏まえた所得税・住民税を差し引いた手取り額の目安を計算するWebアプリ。HAKONIWA LAB([[takehome-calculator]]・[[furusato-simulator]]と同じ計算機型)の7本目のツール。ビルドツール不要のVanilla HTML/CSS/JS。

## ローカルでの動作確認

```
cd retirement-simulator
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。`index.html` を直接ダブルクリックしても動作する(外部通信は一切行わない)。

## ファイル構成

```
retirement-simulator/
├─ index.html          … 入力フォーム+結果表示のSPA本体
├─ css/style.css        … 他アプリと同じCSS変数デザインシステム(コピー)
└─ js/
    ├─ calculate.js       … 退職所得控除・分離課税の計算ロジック(純粋関数、DOM非依存)
    └─ app.js             … フォームの入力受付・DOM描画
```

## 計算ロジックについて

退職金は給与とは別に「退職所得」として**分離課税**される特殊な税制。`js/calculate.js`に実装。

1. **退職所得控除額**: 勤続年数(端数切り上げ)20年以下は「40万円×勤続年数」(最低80万円)、20年超は「800万円+70万円×(勤続年数−20)」。
2. **課税対象の退職所得**: 原則「(退職金−退職所得控除額)÷2」。ただし2022年度改正により、勤続年数が5年以下の場合(短期退職手当等)、控除後の金額が300万円を超える部分については1/2課税が適用されない(150万円+(控除後金額−300万円))。
3. **所得税**: 退職所得に対して、給与所得等とは合算せず単独で超過累進税率表を適用(分離課税)+復興特別所得税2.1%。
4. **住民税**: 退職所得×10%(道府県民税4%+市町村民税6%)、こちらも分離課税。

### 検証(2026-08-02)

一般的な退職所得控除の計算例と照合済み:
- 勤続38年・退職金2000万円 → 控除額2060万円(800万+70万×18) > 退職金のため課税所得0円、手取り2000万円全額
- 勤続20年・退職金1000万円 → 控除額800万円、課税所得100万円、手取り約984.9万円
- 勤続3年・退職金150万円(短期退職手当等) → 控除額120万円、控除後30万円(300万円以下のため通常の1/2課税)、手取り約147.7万円

いずれも手計算での検算と一致(端数処理による1円未満の誤差は許容)。

**注意**: 本シミュレーターは一般的な会社員(役員以外)の退職一時金を想定した概算。確定拠出年金(iDeCo等)の一時金受取、役員退職金(特定役員退職手当等、1/2課税が適用されない)、複数の退職金の合算調整がある場合は計算結果が異なる。年度が変わったら所得税率表を再確認すること。

## マネタイズ導線

初期実装(2026-08-02)時点ではアフィリエイト導線は未実装。takehome-calculator/furusato-simulatorと同様、`#ad-slot-result-bottom`(AdSense用プレースホルダ)と`#lead-form`(Buttondown、`hakoniwalab`アカウントと接続済み)を設置。将来的な候補としては、退職・老後をテーマにした資産形成相談・iDeCo/NISA関連のアフィリエイト案件が候補(insurance-checkerで承認済みの家計相談系案件を流用できる可能性あり)。

## クロスリンク

結果画面からtakehome-calculator(在職中の手取り計算)・insurance-checker(退職後の保障)・career-checker(転職・再就職)へ誘導。takehome-calculator側からも本アプリへの逆方向リンクを追加済み。
